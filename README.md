# AIMLCZG521 Conversational AI — Assignment 2 (PS1)
## End-to-End Research Assistant with Multi-Source Synthesis and Alignment Analysis

### Repository layout
| Path | What it is |
|---|---|
| `Assignment2_PS1_ResearchAssistant.ipynb` | **The submission notebook** (generated by `build_notebook.py`, then executed) |
| `ra/` | Library code: one module per concern (prompting, tools, agent, memory, retrieval, synthesis, evaluation, …). The notebook embeds every module through `%%writefile`, so it is self-contained |
| `nb/` | Notebook section sources (markdown + experiment code) and `inferences.md` (inference text written after execution) |
| `data/` | NQ subset, Wikipedia articles, **synthetic** curated corpus (`curated/author_corpus.py`) and **synthetic** episodic sessions; `build_data.py` regenerates all of it |
| `outputs/` | Figures, `results.json`, audit-trail JSONs, Self-Instruct dataset |
| `report/` | Final PDF report |
| `PLAN.md` | Build plan and task-by-task design |

### How to run
```bash
pip install -r requirements.txt
cp .env.example .env            # then set LLM_BACKEND=gemini and GEMINI_API_KEY=... (or a Groq key)
python build_notebook.py        # (re)assemble the notebook from nb/ + ra/
python -m nbconvert --to notebook --execute --inplace Assignment2_PS1_ResearchAssistant.ipynb --ExecutePreprocessor.timeout=-1
```
* Every LLM call is cached in `cache/llm_cache.sqlite`. A second run replays the cache in a few minutes and reproduces the same numbers.
* On a **free tier** (Gemini or Groq), daily request/token limits may be reached part-way through. The client then falls back to the next model in the role's list (`ra/config.py`). Re-running the next day refills any calls served by fallback models from the preferred model, because the cache prefers it.
* `LLM_BACKEND=mock` runs the whole notebook offline with a dummy model. It is for plumbing tests only; its results are meaningless.
