## Backend & reproducibility
* LLM backend: **Groq** (OpenAI-compatible API). Roles: `generator` (Llama-3.1-8B), `judge` (Llama-3.3-70B — a different, larger model to reduce self-preference bias), `long_context` (Llama-4-Scout). Fallback lists per role; the model that actually served each call is logged.
* Every LLM call is cached on disk (`cache/llm_cache.sqlite`) keyed by (model, messages, params). Re-running the notebook replays identical outputs → reproducible results; the original latency/tokens are stored with the cache entry.
* Seed `42` everywhere (python, numpy, torch, sampling, synthetic latency/failure injection).
* Cost always reported with the assignment's GPT-4o pricing ($5 / 1M in, $15 / 1M out).

## Task-by-task implementation
1. **Prompting** — Zero-shot, Few-shot (3 hand-written exemplars), CoT, ToT (3 paths + evaluator), APE (LLM proposes 5 instructions, scored on a separate APE-dev set). Every technique gets the same evidence pack per question. Correctness = rule fixed *before* evaluation (key-fact coverage ≥ 60 %, no contradiction, conflicts acknowledged for ambiguous; gold-answer match for simple). Depth = fixed lexical step-counting rule.
2. **Function calling** — 6 tools with JSON Schemas + Pydantic models; JSON-mode ReAct loop written from scratch; parallel execution with ThreadPool; 6 safety mechanisms; RBAC, PII output filter, parameterized SQLite queries, tool-output sanitisation; attack suite with blocked-by-defense chart.
3. **Memory/RAG** — deque working memory + LLM rolling summary; 50 synthetic episodic sessions in FAISS; chunking (fixed 256/512, semantic, recursive × overlap 0.1/0.2/0.3); CoT decomposition; iterative refinement (≤3); BM25 + FAISS + RRF hybrid; cross-encoder; ablations; context-engineered prompt with token breakdown & classification; lost-in-the-middle on 10K+ token context; HyDE + CRAG vs baseline.
4. **Synthesis** — credibility weights; weighted RRF; LLM conflict detection + 3 resolution strategies scored against gold adjudications; APA citations; claim verification + self-correction; noisy-OR confidence + ECE; single vs multi-source; RAG Triad judge with anchored rubrics + Cohen's κ (needs human labels — see below).
5. **Alignment** — Self-Instruct pipeline (ROUGE-L dedup implemented from scratch, output-first/input-first); DPO loss worked numerically; PEFT memory calculator; GRPO advantage demo; paradigm comparison (zero-shot vs RAG vs simulated FT).
6. **Integration** — `ResearchAssistant` class, 4-turn conversation, JSON audit trail + rendered report, 10 held-out complex + 50 NQ held-out evaluation, cost/latency P50/P95, architecture diagram, monitoring.
7. **Decisions & cost** — decision table auto-filled from experiment results; routing cost maths; measured quality vs cost of 3 Groq model sizes → Pareto dashboard.
